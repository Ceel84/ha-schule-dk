# Digitales Klassenbuch (schule.dk) Integration für Home Assistant

Diese Integration ermöglicht das automatische Abrufen des Stundenplans von `schule.dk`.

## Installation über HACS
1. In HACS oben rechts auf die drei Punkte klicken -> **Benutzerdefinierte Repositories**.
2. URL dieses Repositories einfügen und als Kategorie **Integration** wählen.
3. Integration installieren und Home Assistant neu starten.
4. Unter **Einstellungen -> Geräte & Dienste** hinzufügen.
